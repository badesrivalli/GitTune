# GitTune 🚀

GitTune is an AI-powered developer productivity platform designed to analyze real-time GitHub repository activity, evaluate code health metrics, and generate interactive two-speaker AI developer podcast discussions using Google Gemini.

## 🌟 Key Features
- **Real-Time GitHub Integration:** Fetch live commits, contributor stats, and repository activity.
- **Gemini AI Code Analytics:** Automated code insights, performance reviews, and repository health scoring.
- **AI Podcast Studio (Alex & Sam):** Generates engaging, two-speaker conversational podcast discussions analyzing the codebase.
- **Interactive UI/UX:** Clean, dark-themed developer workspace built with modern web technologies.

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS, Recharts
- **AI Engine:** Google Gemini API
- **Version Control:** Git & GitHub
